# Карта тревог Люменарии

Статический сайт-симулятор для GitHub Pages. Все посетители видят одинаковое состояние: тревоги детерминированно рассчитываются из общего времени.

Карта в интерфейсе полностью векторная: все 34 региона находятся в `assets/lumenaria-map.svg`, а исходный PNG используется только как географический источник для повторной генерации.

## Локальный запуск

Откройте `index.html` в браузере или запустите любой статический HTTP-сервер в корне проекта.

## Публикация на GitHub Pages

1. Загрузите файлы в репозиторий GitHub.
2. Откройте **Settings → Pages**.
3. Выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.

Параметры частоты и вероятности тревог находятся в объекте `CONFIG` в начале `app.js`. Коэффициент `risk` у каждого региона изменяет его индивидуальную вероятность.

## Повторная векторизация карты

Установите OpenCV и запустите:

```bash
pip install -r tools/requirements.txt
python tools/vectorize_map.py
```

Скрипт обновит production-карту `assets/lumenaria-map.svg` и диагностические файлы:

- `assets/lumenaria-map-debug.png` — цвета поверх исходника;
- `assets/vectorization-labels-debug.png` — конечное владение каждым пикселем без границ;
- `assets/lumenaria-map-no-strokes-debug.svg` — итоговые SVG-контуры с `stroke: none`.

Также проверяются наличие всех регионов, пересечения, пропуски суши, multipart-география и подозрительные тонкие компоненты.
